# Caffeine

SwiftUI와 IOKit으로 만든 macOS 메뉴바 절전 방지 앱입니다. 외부 라이브러리나 `caffeinate` 하위 프로세스 없이 기본 기능은 macOS 전원 관리 API를 직접 사용합니다. 덮개를 닫고 쓰는 별도 옵션은 `pmset` 시스템 설정을 변경합니다.

## 기능

- 컴퓨터 자동 잠자기 방지, 선택적으로 화면 자동 꺼짐도 방지
- 15분, 30분, 1시간, 2시간, 무제한 프리셋
- 메뉴바에 남은 시간 또는 감시 중인 앱·작업 이름 표시
- 실행 중인 앱·작업을 이름으로 검색해 선택하고, 해당 프로세스가 종료되면 절전 방지 해제
- AC 전원 연결 중에만 동작하는 옵션
- 배터리 사용 중 잔량이 20% 이하가 되면 자동 해제
- 로그인 시 자동 실행 설정 (`SMAppService`)
- 관리자 인증으로 시스템 잠자기를 차단하는 **덮개 닫아도 계속 실행** 옵션

메뉴바 아이콘을 누르면 시간·화면·보호 옵션을 한 화면에서 설정할 수 있습니다. 선택한 시간은 버튼 강조로, 나머지 옵션은 체크박스로 표시합니다. 패널에서 `Cmd + T`로 자동 잠자기 방지를 켜거나 끄고, `Cmd + Q`로 앱을 종료할 수 있습니다. 시간 프리셋을 변경하면 바로 시작하고 기존 PID 감시는 해제됩니다. 화면 설정 변경에 실패하면 절전 방지를 해제하고 오류를 표시합니다.

**화면 자동 꺼짐도 방지**를 체크하면 화면이 자동으로 꺼지지 않습니다. 체크를 해제하면 화면은 자동으로 꺼져도 컴퓨터의 자동 잠자기는 계속 방지합니다. 밝기는 두 경우 모두 직접 조절할 수 있습니다. 기본 기능만으로는 덮개를 닫아서 발생하는 잠자기를 막지 않습니다.

**앱·작업이 종료될 때까지…**에서 앱 이름을 검색해 선택하세요. Python 같은 프로세스는 **백그라운드 작업도 표시**를 켜서 찾을 수 있습니다. 새로 실행한 항목은 **목록 새로고침**으로 불러옵니다. PID는 같은 이름의 항목을 구분하는 참고 정보이며 직접 입력할 필요가 없습니다. 앱 안의 작업 완료가 아니라 선택한 앱·프로세스의 종료를 감시합니다. 실행 목록은 로컬에서만 읽으며 저장하거나 전송하지 않습니다.

**덮개 닫아도 계속 실행**은 `pmset -a disablesleep 1`을 적용하고, 체크를 해제하면 `pmset -a disablesleep 0`으로 되돌립니다. 켜고 끌 때 macOS 관리자 인증창이 표시됩니다. 비밀번호는 앱이 직접 입력받거나 저장하지 않습니다. 명령 실행 후 실제 설정을 다시 읽으며, 인증 취소·실패를 켜짐으로 표시하지 않습니다. 패널을 열 때와 열려 있는 동안 5초마다 시스템 상태를 확인하므로 터미널에서 바꾼 설정도 반영합니다.

이 옵션은 **별도 시스템 설정**으로, 기본 기능의 타이머·프로세스 종료·AC 전원 조건·배터리 20% 자동 해제와 연결되지 않습니다. 앱 종료 후에도 유지되며, 앱을 종료하거나 기본 기능을 꺼도 해제되지 않습니다. 켜져 있으면 메뉴바에 노트북 아이콘과 패널 상단의 상태 문구를 표시합니다. **가방에 넣기 전에는 반드시 직접 해제하세요.** 시스템 잠자기 전체에 영향을 주므로 Apple 메뉴의 잠자기도 사용할 수 없게 됩니다. [Apple의 기존 OS X Server 설명](https://support.apple.com/ja-jp/101114)에 나온 설정이며, 실제 덮개 닫힘·Wi-Fi·원격 연결 유지는 해당 Mac에서 확인해야 합니다.

## 요구 사항

- Apple Silicon Mac — 제공되는 빌드 스크립트는 `arm64`를 대상으로 합니다.
- macOS 13 이상
- Swift 5.9 이상과 macOS SDK를 제공하는 Xcode 또는 Command Line Tools

## 빌드 및 실행

```bash
git clone https://github.com/Felix0708/Caffeinate.git
cd Caffeinate
./scripts/build_app.sh
open Caffeine.app
```

빌드 스크립트는 로컬 앱 번들을 생성하고 ad-hoc 서명을 적용합니다. Developer ID 서명이나 Apple 공증을 수행하지 않습니다. 빌드된 앱은 저장소에 포함하지 않습니다.

응용 프로그램 폴더에 설치하려면 다음을 실행합니다.

```bash
./scripts/install.sh
```

설치 스크립트는 다시 빌드한 뒤 실행 중인 `Caffeine`을 종료하고 `/Applications/Caffeine.app`을 교체합니다. 해당 폴더에 쓰기 권한이 없으면 `~/Applications`에 설치합니다. 설치 후 직접 앱을 실행하세요.

## 검사

```bash
bash scripts/check_app_state.sh
```

실제 `AppState`와 테스트용 전원 관리 객체를 함께 컴파일하여 다음을 검사합니다.

- PID 감시에서 타이머로 전환할 때 감시 상태 정리
- 모드 변경 및 활성화 실패 후 비활성 상태와 오류 메시지 유지
- AC 전원과 배터리 조건에 따른 활성화 거부
- 잘못된 PID와 켜기/끄기 동작
- 무제한 유지 중 불필요한 상태 갱신 방지 및 모드 변경 시 타이머 유지
- 앱·작업 검색, 테스트 프로세스의 목록 표시와 종료 후 새로고침, 선택 실패 처리
- 시스템 잠자기 상태 파싱, 실제 상태 조회, 모의 변경·인증 취소·실패·중복 요청과 변경 후 재확인 (검사 중 시스템 설정을 변경하지 않음)

회귀 검사와 로컬 앱 빌드·서명 검증은 완료했습니다. 실제 화면 절전, 배터리 전환, 로그인 자동 실행의 UI 및 하드웨어 동작은 별도 확인이 필요합니다. 메모리 사용량이나 다른 앱과의 성능 비교는 측정하지 않았습니다.

## 구현과 범위

| 파일 | 역할 |
| --- | --- |
| `Sources/Caffeine/CaffeineApp.swift` | 메뉴바 UI |
| `Sources/Caffeine/ProcessPickerView.swift` | 앱·작업 검색과 선택 |
| `Sources/Caffeine/RunningProcess.swift` | macOS 실행 목록 조회 |
| `Sources/Caffeine/AppState.swift` | 활성 상태, 타이머, 감시 및 보호 조건 |
| `Sources/Caffeine/SystemSleepSetting.swift` | 시스템 잠자기 설정 조회, 관리자 인증 및 변경 후 재확인 |
| `Sources/Caffeine/PowerManager.swift` | IOKit assertion, 전원 정보, PID 생존 확인 |
| `Tests/AppStateCheck.swift` | 상태 전환 회귀 검사 |
| `scripts/` | 빌드, 설치, 검사 |

작동 중 화면 옵션을 체크하면 `PreventUserIdleDisplaySleep`, 해제하면 `PreventUserIdleSystemSleep` assertion을 사용합니다. 배터리 정보는 `IOPowerSources`에서 읽고, 프로세스 생존 여부는 `kill(pid, 0)`으로 확인합니다.

- 활성 상태에서 타이머·PID·전원 조건을 1초 주기로 확인합니다. 타이머는 tick마다 감소하므로 시스템 잠자기나 이벤트 처리 지연 후 정확한 종료 시각을 보장하지 않습니다.
- AC 전원 옵션은 앱의 실행 조건이며, `caffeinate -s`와 동일한 assertion을 사용하지 않습니다.
- `caffeinate`의 디스크 절전 방지(`-m`), 사용자 활성 선언(`-u`), 명령 실행 및 CLI 동기화 기능은 구현하지 않았습니다.
- 기본 IOKit 기능은 덮개 닫힘이나 사용자가 직접 요청한 잠자기를 막지 않습니다. 별도 시스템 잠자기 설정에는 관리자 인증이 필요합니다.
- 화면·시간·보호 옵션은 앱을 다시 실행하면 초기값으로 돌아갑니다. 로그인 자동 실행 여부는 macOS에서 읽습니다.
